Docker Desktop extension for macOS

Run OpenClaw locally without fighting the localhost gap.

This project packages OpenClaw as a Docker Desktop extension with start, stop, update, diagnostics, and local Ollama setup controls for a Mac-first developer workflow.

What it solves

A thin wrapper around the sharp edges.

01

Localhost-only bridge

The runtime adds a small socat bridge so OpenClaw can be reached from the host at 127.0.0.1 on Docker Desktop for macOS.

02

Persistent local state

OpenClaw config, auth profiles, and user state live in a named Docker volume, so update and restart flows do not wipe the workspace.

03

Host Ollama setup

The extension can detect host Ollama models and configure OpenClaw to use one, keeping local-model setup inside the existing Docker Desktop UI for offline use after the model is downloaded.

Current extension UI

Start, update, inspect, and launch from one panel.

The extension dashboard manages the service container, checks runtime image freshness, exposes diagnostics, and opens the canonical OpenClaw Control UI with gateway-token bootstrap.

Quick start

Develop locally

make install-dev

Use this repo path when changing the extension UI, wrapper image, or release automation.

Current boundaries

Clear constraints are part of the product.

  • Tested first on Docker Desktop for macOS and Apple Silicon.
  • The wrapper improves local isolation, but it is not a hardened sandbox.
  • Provider auth beyond the Ollama setup flow stays owned by OpenClaw.
  • Bundled local inference is deferred until host Ollama usage shows real demand.
